# 美团商城营销报名系统 · 项目经验

> 后端开发 | Java / Spring / DDD / 分布式架构

---

## 项目背景

美团商场主题活动营销报名管理后端服务，覆盖**营销活动报名、档期排期、库存盘货、商家招商、促销选品**全链路，支撑商场日常营销活动的提报与执行。

| 消息队列 | Mafka（美团 Kafka，30+ 生产/消费者） |

## 架构亮点

### 多模块 + DDD 领域驱动分层

老模块（service / dao / web / client）按经典三层分层；新模块（calendar / inventory / merchant / pick）全面采用 DDD 四层架构：

```
interfaces     接口层（Thrift 实现、参数校验、Assembler）
application    应用层（编排业务流程、DTO 转换）
domain         领域层（核心业务逻辑、领域服务、Crane 任务）
repository     基础设施层（DB / ES / Thrift / Mafka 网关）
```

通过模块垂直拆分实现业务解耦与独立演进。

### 观察者模式解耦业务流程

基于 Spring `ApplicationEvent` 实现事件发布订阅（提报变更、档期变更、白名单变更等），核心业务与下游联动（ES 刷新、消息推送）通过事件解耦，降低代码复杂度与耦合。

### 数据异构支撑复杂查询

自研 `DataAggregate` 数据聚合框架，将 MySQL 报名 / 档期数据异构同步至 Elasticsearch，支撑工作台多维度筛选、大列表分页查询等高复杂度场景。

### 高可用：限流 + 降级 + 线程池隔离

- Thrift 调用层通过 `OneLimiter` 限流器控制下游 QPS
- 超限参数自动降级为分批串行调用
- 异构消费支持独立线程池隔离，避免拖垮主链路
- Lion 配置中心提供线上动态开关

### 分布式一致性保障

`@Transactional` 保证本地事务，结合 Mafka 消息队列实现最终一致性；Crane 定时任务做数据对账与 ES 自修复；DBus 监听 Binlog 触发库存 / 报名数据异构刷新。

## 核心职责与技术产出

### 1. 库存盘货模块核心开发（DDD 分层架构）

负责 `inventory` 模块开发，采用 DDD 四层架构，将盘货业务按领域拆分，实现库存预测、订货量风险校验、数据权限控制等核心能力。

- **盘货数据权限批量更新**：通过递归查询采购组织 ID 子树、过滤非启用节点、限制 Excel 填写层级（三级以内）等校验，支持运营人员批量配置盘货权限，结合 Lion 动态开关实现灰度上线

### 2. POI-RPC 接口性能优化

对盘货门店（POI）查询网关进行重构，合并冗余 Gateway、精简调用链路，单次改造**减少 491 行代码**（删减 76%），降低下游 Thrift 调用次数，提升盘货列表查询性能。

### 3. 盘货支持门店维度建促销

将促销粒度从区域（Area）下钻至门店（POI）维度，实现 `DisplayAreaLimit → AreaLimit` 维度转换，覆盖 Excel 解析门店集、采购编辑校验、查询接口兼容等全流程，支持满额一口价等新玩法批量盘点。

### 4. 补差协议与监控打点

负责补差协议（Rebate Agreement）创建链路开发，统一 tag 维度；接入 APM 监控打点，实现补差信息创建全链路可观测，支撑线上问题快速定位。

### 5. 定时任务治理与稳定性保障

治理盘货模块 Crane 定时任务（促销一致性检查、备货 SKU 状态变更、临时商品清理等），调整任务执行条件与参数；补充单例测试覆盖，提升任务稳定性。

开发 **ES 数据修复 HTTP 接口**，支持线上提报单、白名单 ES 数据手动修复，缩短故障恢复时间。

### 6. 促销状态联动与通知

- 实现促销下线时状态自动同步至盘货模块，保证数据一致性
- 支持盘货品类筛选只传选择节点 ID，优化筛选体验
- 参与 52MD 营销计划通知提醒功能开发，支持告警类型配置与通知月份动态调整

### 7. 供应商活动提报与采运联补

参与供应商活动提报 4 期开发，支持提报商品券 / 赠品券；参与采运联合补贴 2 期、盘货提效优化 2 期、人工 K 量风险预警等需求迭代。
