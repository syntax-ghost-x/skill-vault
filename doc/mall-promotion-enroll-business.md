# 美团商城营销报名系统 · 业务要点

> 营销活动提报 · 库存盘货 · 档期日历 · 商家招商 · 促销选品

---

## 业务定位

美团商场主题活动营销报名管理后端服务，是商场营销活动的**统一提报入口与执行中枢**，覆盖从活动排期、商家招商、商品盘货、促销提报到补贴回收的营销全链路，将原本依赖线下大象 / Excel 的采购-运营-订货协同全面线上化。

---

## 五大业务板块

### 1. 营销活动提报（Enroll）

统一提报平台，整合原 noah.manage / hermes / noah.push 三个老服务，支持 **20+ 种促销玩法**的提报管理。

- **促销玩法覆盖**：满减、折扣、一口价、秒杀、满额一口价、买赠、满额赠、满件赠 / 折、第二件 N 元 / N 折、优惠套装、加价购、N 元 M 件、订单满额赠、会员价、会员免费菜、会员折扣等
- **营销展位体系**：活动与展位父子结构管理，支持秒杀坑位限制、品类坑位、自动限购等复杂展位规则
- **商品池管理**：监听档期 / SKU / 促销 / CSPU-SKU 变更消息，实时维护选品池
- **盘货校验统一入口**：档期准入校验、互斥叠加校验、促销黑名单校验、促销活动校验四道关卡
- **消息中心**：消息查询 / 已读 / 聚合展示 / 大象通知，高优消息定时提醒

### 2. 库存盘货（Inventory）—— 三方协同核心

解决采购 ↔ 运营 ↔ 订货三方协同问题，将商品规划、补贴信息、订货量、价格全链路线上留痕，保障节奏一致。

**盘货数据流闭环：**

```
采购上传 Excel
    ↓
待盘商品数据
    ↓
运营线上 / 线下盘点
    ↓
已盘数据
    ↓
自动同步价格系统（活动原价）/ 订货系统（运营 K 量）
    ↓
运营筛选未建促销的已盘数据 → 创建促销活动
    ↓
系统定时根据促销信息与采购数据 → 生成补差协议合同
    ↓
推送价格系统创建补差合同
```

**三大核心流程：**

| 流程 | 说明 |
|---|---|
| 渲染与校验 | 补全 SKU 价格 / 名称 / 经营指标 / 档期；含负毛利风险校验 |
| 批量创建促销 | 商品筛选 → KEY 生成 → 活动聚合（token 防重复）→ 分页查询 → 批量创建 → 进度查询 |
| 定时补差协议 | 按促销参与品匹配采购补差信息 → 生成补差合同 → 推送价格系统 |

**关键业务能力：**

- **供应商补贴回收闭环**：活动生效 / 结束后自动生成补差协议，回收供应商补贴，避免遗漏
- **订货量管理**：系统预估日销 + 运营人工 K 量，活动前同步订货系统（RDC / FDC）
- **数据权限控制**：按采购组织、品类维度控制盘货权限

### 3. 营销档期日历（Calendar）

- **52 周营销日历（52MD）排期**：全年营销活动档期规划与排期管理
- **品类趋势分析**：品类趋势排名、趋势汇总，辅助运营决策
- **AIGC 赋能**：AI 辅助营销计划生成与建议
- **营销计划通知**：活动通知提醒、节假日 / 峰日标注、操作日志
- **活动资源管理**：活动模板、活动资源关联管理

### 4. 商家招商（Merchant）

- **商家入驻报名**：供应商线索导入 → 筛选优选 → 入驻提报 → 审核流程 → 合同创建
- **招商与商资源管理**：系统化导入筛选供应商线索，优质商机识别、引入及转化；储备商资源池管理
- **商家活动提报**：支持商品券、赠品券等券活动提报
- **自动上架**：审核通过后自动上架，VSS 消息同步

### 5. 促销选品（Pick）

- **促销选品池**：基于提报变更事件驱动选品池更新
- **选品事件消费**：监听提报变更消息，动态维护选品池数据

## 协同关系总览

盘货是连接采购、运营、订货三方的协同枢纽：

| 协同方 | 痛点 | 系统解决方式 |
|---|---|---|
| 采购 ↔ 运营 | 商品规划与实际偏差、供应商资源浪费 | 采购与供应商谈好补贴后上传商品及补贴信息；运营盘点时有补贴的商品优先建促销 |
| 采购 ↔ 运营 | 未收回补贴 | 运营创建促销后，按活动商品匹配采购补差信息，自动生成补差协议推送采购 |
| 运营 ↔ 价格 | 半价日原价与促销价合理性 | 采购 / 运营提前填写活动原价，同步商品系统供活动期间调价，满足毛利考核 |
| 采购 ↔ 运营 ↔ 订货 | 三方订货量对不齐、RDC 录入缺失 | 盘货时可调整订货量，活动前同步订货系统 |
