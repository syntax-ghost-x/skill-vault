# 美团商城促销管理服务 · 业务要点

> 面向简历的业务能力梳理。与《技术要点》互补:本文聚焦"系统做什么、解决什么业务问题",技术实现细节见同名技术文档。

---

## 一、业务定位

美团商城促销活动**全生命周期管理平台**,为商城运营/采购人员提供促销活动的创建、编辑、审批、上下线、冲突校验、预算补贴、价格管控等一站式管理能力;并通过缓存契约 jar 与 Thrift RPC 接口,将促销数据供给 C 端促销计价、展销大搜、价签系统等下游消费方。

服务覆盖**小象(含 H 业态)与快乐猴(N 业态线下超市)**双业态,支撑 **20 种促销玩法、41 个 Thrift RPC 接口**,贯穿活动从创建到结束的完整状态机。

---

## 二、核心业务能力

### 1. 促销活动全生命周期管理

覆盖活动从创建到结束的完整状态机:**待生效(INIT)→ 生效中(ONLINE)→ 已下线/已结束(EXPIRED)**,草稿(DRAFT)可编辑。

| 能力 | 说明 |
|---|---|
| 创建/编辑 | 支持系统接口(system)与前端页面(web)两种入口,按活动类型分别校验门槛/优惠字段,幂等锁防重复提交 |
| 上下线与状态流转 | 手动下线、到期自动下线、出清折扣 CAS 下线、加价购补品/调价/删品(modifyPromotionSku) |
| 批量操作 | 活动批量复制(batchCopyPromotion)、批量补品调价 |
| 营销日历 | 活动生效后自动推送营销日历,供前端/价签消费 |

### 2. 20 种促销玩法矩阵

通过"**门槛 × 优惠**"组合模型,支撑全量促销玩法:

| 玩法 | 业务说明 |
|---|---|
| 满减 / 满额赠 / 满件赠 | 满金额/满件数触发减免或赠品 |
| 一口价 / 折扣 / 会员价 / 会员折扣 | 直降价或折扣,含会员专属 |
| 秒杀一口价 / 临期秒杀 / 积压秒杀 | 秒杀场景,临期/积压品自动选品进秒杀 |
| 满额一口价 / 满件折 | 满额直降 / 满件折扣 |
| 买赠 / 加价购换购 | 买赠循环赠品、加价购换购品 |
| N 元 M 件 / 第二件 N 元 N 折 | 多品总价一口价、第二件阶梯优惠 |
| 优惠套装 / 订单满额赠 | 组套品、订单维度满额赠 |
| 会员免费菜 | 会员免费赠品,含多门槛/膨胀配置 |

- **门槛**:无 / 金额 / 数量 / 第 N 件 四种 + **多阶梯定价**(N 元 N 件)。
- **优惠**:特价 / 满减 / 折扣 / 赠品 / 换购 五种。
- **维度**:单品(Item,按 skuId)/ 多品(Multi,全局)双规则维度。

### 3. 促销规则与限购配置

- **规则配置**:门槛 + 优惠组合,支持多阶梯;单品按 skuId 维度、多品全局维度。
- **限购体系**:活动维度 / 单门店 / 全门店三层,覆盖每单限购总款数、每人总参与次数、每人日参与次数、每单最小购买量等多维限购。
- **投放范围**:门店(POI)/ 城市 / 站群三级区域投放,渠道(APP/小程序/线下/微信等)与活动场景维度限制。

### 4. 促销冲突校验

解决"新建活动与已有活动是否互斥/可叠加"的业务问题,提供 **8 类对外冲突校验接口**:

- **覆盖场景**:商品集主品、买赠循环赠、全场集加价购、订单满额赠、品类集、会员免费菜、频道页一口价/秒杀。
- **互斥/可叠加判定**:时间交集 + 用户限制(会员类型)一致 + 满额预过滤后,按促销组合类型分发判定,可叠加活动从冲突集剥离至兼容集。
- **频道冲突 + 最低价校验**:超级秒杀场景下比对频道间最低价,防掉坑。

### 5. 预算补贴管理

解决"补贴成本分摊给谁出、出多少"的业务问题,双链路设计:

| 链路 | 业务说明 |
|---|---|
| 预算承担方补贴 | 平台内部预算资金池分摊(小象/供应商作为承担方),集成龙门财务平台创建 AN(资金池活动流水)锁定预算,支持活动维度/SKU 维度配置,PN 权限与余额校验 |
| 供应商补差协议 | 供应商出资补差(销量补差/库存补差/定额降价补差/定额促销费等),由盘货系统回收,不涉龙门 AN |

- 联营商 PN 校验、比例和校验(万分比,供应商承担方不纳入求和)。

### 6. 价格管控(防倒挂 / 跟价 / 锁价)

| 业务线 | 说明 |
|---|---|
| 价格倒挂校验 | 校验主品与关联品(冰镇/常温、大小包规、大米真空失空等)是否满足价格关系表达式,拦截或提示 |
| 防倒挂跟价 | 活动审核通过后自动为关联品创建一口价促销,从源头避免倒挂 |
| 频道跟价 | 高优先级频道活动价格高于低优先级频道时自动跟出低价活动,防掉坑 |
| 锁价校验 | 校验门店-SKU 是否处于不可变价时段 |

### 7. 审批流程

集成 Gravity 工作流引擎实现促销活动审批:

- **审批流配置**:按经营城市/组织/业态/标签路由流程定义,节点支持条件指标表达式(Aviator 求值)+ 多角色审批人(固定 MIS / 大象组织 / 逐级上级 / 自定义审批组 / 接口审批人)。
- **运行态**:我的申请/我的审批、提交/完成/批量完成/撤回/驳回,审核回调(通过/驳回可修改/不通过)。
- **指标计算**:毛利率、订货方式、预估订货量、采购组织类目、补贴 PN 等 8 个条件计算器驱动节点命中。
- **免审配置**:特定标签/开关支持自动过审。

### 8. 风险管控

- **事前风险校验**(同步 RPC):创建活动时对 SKU 价格(毛利率/优惠率阈值)、预估订货量(人工/系统预估量比、可订货门店占比)做风险判断,返回风险文案不阻断建活动。
- **事后巡检监控**(定时任务):已生效活动数据正确性、互斥冲突、DB/缓存/ES 一致性、库存配置、全场加价购覆盖巡检,命中告警不修复。

### 9. 选品与活动码

- **临期特惠自动进秒杀**:每小时按门店轮巡,从商品接口取临期品(选品重构),按原价/库存/坑位配置/黑名单/近 7 日均销售额筛选排序,自动创建秒杀活动并过审。
- **活动码**:N 业态出清活动码 + 顶层通用活动码,绑定龙门 AN,支持批量创建、特殊品类(香烟等)禁建。

### 10. SKU 黑名单与 POP 场景

| 能力 | 业务说明 |
|---|---|
| SKU 黑名单 | 管理指定 SKU 在门店/城市/促销类型/终端场景下不可创建促销,M 端创建拦截 + C 端展销大搜查询 |
| POP 打印标识 | 促销商品"打印 POP"标识,用于线下门店促销互斥与收银/小票打印控制,生效期间锁定不可改价改品 |

### 11. 价签算价(C 端供给)

为 H 端/N 端价签系统提供门店-SKU 维度的促销价计算:

- 召回该 SKU 参与的全部活动 → 过滤/排序/互斥选最优 → 计算售价/会员价/出清价/kg 价。
- 通过独立 cache-starter 契约 jar 将缓存值对象供给 C 端促销计价服务,读端不引入管理服务重型依赖。

### 12. 模板与统一配置中枢

- **活动模板**:20 种促销类型模板,前端创建页展示门槛选项/维度/标签/限制/按钮配置。
- **校验规则项配置**:全部促销类型共用一份规则项配置,差异由 Lion 动态配置,**新增促销类型无需改代码**。
- **统一渠道映射**:appName↔channel、活动场景↔mcSource 标准化。

## 四、可量化业务描述(简历条目参考)

- 负责美团商城促销管理平台研发,支撑促销活动**全生命周期管理**(创建→审批→上线→下线→到期),覆盖 **20 种促销玩法**(满减/一口价/折扣/买赠/加价购/N 元 M 件/秒杀/会员折扣/免费菜等)与**双业态**(小象含 H 店 / 快乐猴 N 业态超市)。
- 设计"**门槛 × 优惠**"组合规则模型,支撑多阶梯定价与单品/多品双维度配置,实现限购(活动/单店/全店/每单每人)、投放范围(门店/城市/站群)、渠道与场景多维限制的灵活配置。
- 实现 **8 类冲突校验接口**与互斥/可叠加判定引擎,解决新建活动与存量活动冲突问题;搭建预算补贴双链路(平台预算 AN 锁定 + 供应商补差协议),覆盖补贴成本分摊全场景。
- 搭建价格管控体系(倒挂校验/防倒挂跟价/频道跟价/锁价)与 Gravity 审批流引擎(条件指标 + 多角色审批人),保障促销价格合规与审批流转。
- 建设临期特惠自动选品进秒杀、SKU 黑名单、POP 打印互斥、价签算价等业务能力,并通过 cache-starter 缓存契约 jar 供给 C 端促销计价/展销大搜/价签系统消费。
