# 小象超市主题活动商品提报平台 · 业务要点

> 面向采购运营团队的活动招商系统，为核心业务系统提供「选品 → 提报 → 审批 → 投放」全链路管理能力。运营在小象超市（原美团买菜）主题活动场景下，从候选商品池中筛选商品、发起提报、走多级审批、最终将促销投放至促销系统生效，覆盖活动招商全流程。

---

## 业务全链路

```
候选池筛选  →  提报申请  →  提报校验  →  多级审批  →  促销投放  →  活动生效
   选品         增删改      16类规则     Gravity BPMN    聚合+投放      状态机流转
```

- **候选池筛选**：运营从十万级商品池中按品类、城市、管理状态、毛利、库存、销量预测等 30+ 维度筛选目标商品
- **提报申请**：对选中商品发起提报（新增 / 编辑 / 删除 SKU、供方提报），支持批量操作
- **提报校验**：提交前过 16 类业务规则校验（鉴权、黑名单、灰度、时间窗、互斥叠加、负毛利、因子等），区分强阻断与弱提示
- **多级审批**：按采购组织 / 部门 / 管理城市匹配审批流，指标驱动条件路由，多级节点审批
- **促销投放**：审批通过后按业务规则聚合为促销活动，投放至促销系统，失败自动重试
- **活动生效**：活动任务状态机流转（草稿→报名中→待生效→生效→自动下线），定时触发生效与下线

## 核心业务模块

### 1. 候选商品池管理（选品中枢）

业务问题：运营需从海量商品中挑选参加活动的商品，需多维度筛选与提报前选品。

业务能力：
- **候选池构建**：商品基础信息（名称 / 图片 / SPU / BG 品类 / 组织品类 / 标签）+ 城市维度管理状态 + 外部信息（促销记录 / 提报记录 / 补贴）聚合为候选池
- **多维度筛选**：工作台支持 30+ 数据维度筛选——品类路径、管理状态、城市、商品标签、毛利、库存、销量预测、WAC 成本价、白名单等，按前端展示列懒加载取数
- **提报统计**：两级聚合（按品类 → 按城市）统计提报情况
- **数据自动刷新**：商品基础信息 / 管理状态变更通过 binlog 同步至候选池，保持数据新鲜
- **组织品类回填**：游标分页批量回填组织品类信息，支持失败续跑

### 2. 商品提报管理（提报申请）

业务问题：运营对选中的商品发起提报，需支持单条与批量、SKU 与供方两类提报物。

业务能力：
- **SKU 提报**：新增 / 编辑 / 删除提报商品，含预测销量计划（校验库存风险上下限）、促销配置、区域限制、客户限购
- **供方提报**：供应（蓝莓）维度的提报，独立校验链（供应基础校验 / 供应条目校验 / 供应重复校验）
- **批量提报**：单次 5000 行批量导入 / 导出 / 编辑，支持条件筛选批量、文件上传批量、历史保存批量三种数据来源
- **提报暂存与提交**：支持草稿暂存、部分提交审批、全部提交审批
- **提报快照**：操作前后 diff 记录（新增 / 编辑 / 删除 / 审批场景），留存操作轨迹

### 3. 提报校验体系（16 类业务规则）

业务问题：提报前需校验商品是否符合活动准入与互斥规则，避免不合规商品进入审批流。

业务能力——16 类校验规则：
- **权限类**：鉴权校验（AuthPermission）
- **准入类**：黑名单（Blacklist）、灰度（Gray）、CRM 客户（CrmCustomer）、白名单
- **基础类**：基础校验（Base）、促销基础（PromotionBase）、提报一致性（EnrollSkuConsistency）、MADE 与组商品（MadeAndGroupSku）
- **时间类**：时间窗校验（TimeRange）、有效时段冲突检测
- **业务规则类**：因子校验（Factor，调用因子引擎）、互斥叠加（ExclusiveSuperposition）、负毛利（NegativeMargin）、流量一致性（TrafficConsistency）、流量基础（TrafficBase）、预测计划明细（PredictPlanDetail）、促销活动（PromotionActivity）
- **强弱分离**：强校验阻断保存、弱校验仅提示不阻断，使「有警告但可保存」的商品不被误杀
- **波次并行**：16 个校验器分波次并行执行（鉴权 → 基础 → 业务 → 终校验），波次间剔除强校验失败商品，缩短整体校验耗时
- **促销形态适配**：14 种促销形态各有专属校验器（阶梯重复 / 阶梯档位 / 满减门槛 / 数量门槛 / 折扣力度等）

### 4. 多级审批工作流（指标驱动条件路由）

业务问题：提报需多级审批，不同组织 / 城市 / 毛利水平走不同审批链路，审批节点依赖动态指标做条件路由。

业务能力：
- **审批流配置**：按「采购组织 + 采购部门 + 管理城市」匹配审批流定义，配置节点级条件、自定义审批组、组织架构路由（大象部门 / 上级审批）、接口指定审批人
- **指标驱动条件路由**：审批节点条件依赖动态计算的 10 类指标——毛利（两种口径）、计划订货量、距门店最早到货天数、补贴分摊 PN、白名单、经营城市、采购组织品类、订货方式等
- **多级审批操作**：提交全部 / 部分提报审批、批量审批、单条审批、撤回、取消流程、查询审批进度
- **审批进度可视化**：返回节点链路图（DAG 结构），前端渲染审批流进度
- **审批详情**：四路并行加载（提报 SKU + 基础信息 + WAC 成本价 + 白名单），展示每条商品的提报类型、促销形态、毛利率、预测计划等
- **回调驱动**：Gravity 审批回调驱动后续投放流程

### 5. 促销投放（聚合 + 投放 + 重试）

业务问题：审批通过后需将分散的提报商品聚合为促销活动并投放至促销系统生效，需保证幂等与最终一致。

业务能力：
- **促销聚合**：按活动名 / 时间窗 / 区域限制 / 促销形态 / 折扣规则 / 客户限购 / 渠道 / 平台预算的复合键聚合，MD5 指纹去重，相同业务键的商品归入同一促销活动
- **14 种促销形态**：直降、秒杀、超级秒杀、第二件 N 元、第二件 N 折、满减、满件折、买赠同、买赠异、换购、满换购、N 元 M 件、试价、品类信息
- **投放分流**：已知促销 ID 走编辑合并、未知走新建，分布式锁 + 双重检查保证并发创建幂等
- **失败重试**：投放异常发重试事件，死信兜底，按事件类型路由重试处理器，保障最终一致
- **状态回滚**：按商品维度拆分成功 / 失败，失败项回滚状态，不做整批回滚

### 6. 活动任务管理（全生命周期）

业务问题：一个主题活动从创建到下线需状态流转、定时生效、白名单管理、截止通知。

业务能力：
- **活动任务生命周期**：状态机流转 草稿 → 报名中 → 待生效 → 生效 → 自动下线，定时任务自动触发状态转移
- **活动配置**：活动名称 / 类型 / 时间窗 / 区域限制 / 提报类型 / 白名单 / 促销配置 / 通知配置，名称查重 + 促销校验
- **白名单管理**：活动级商品白名单维护
- **通知触达**：报名截止定时通知、发布后大象消息通知（事务提交后触发）、待审批聚合通知、审批节点通过通知
- **任务下载**：多文件导出 + 通知组装

### 7. 投放管理（投后运营）

业务问题：审批通过进入投放阶段的商品与供方需可查询、可 cherry-pick（入选 / 驳回）、可取消。

业务能力：
- **投放查询**：商品 / 供方分页查询，含促销信息富化
- **cherry-pick**：入选 / 驳回操作，乐观锁状态流转
- **取消提报**：按条目维度拆分成功 / 失败，不整批回滚
- **批量预校验**：批量编辑 / 删除 / 提交 / 取消前预校验
- **自定义标签**：批量设置 / 清除 / 移除标签，记录前后 diff

### 8. 工作台配置（可定制视图）

业务问题：不同运营关注不同列，需可定制工作台表头与模块。

业务能力：
- **表头定制**：默认列配置来自海马平台，用户级覆盖（显示 / 隐藏 / 排序）存 DB 叠加，支持查询与修改
- **模块配置**：模块级配置来自 Lion 动态配置

### 9. 批量处理引擎（大规模运营操作）

业务问题：运营需批量处理数千行商品提报数据，需断点续传、行级错误隔离。

业务能力：
- **多场景**：新增 / 编辑 / 删除 SKU、新增 / 删除供方、任务清单 SKU / 供方、候选池筛选适配等场景
- **四阶段管线**：准备 → 转换 → 执行 → 提交，每阶段可独立替换
- **行级隔离**：单行失败不阻断整批，聚合成功 / 失败 / 跳过计数
- **文件导入导出**：S3 文件上传下载 + EasyExcel 流式读写，单次 5000 行
- **乐观锁**：并发编辑版本冲突检测
- **风险确认流**：风险项确认后重新校验

## 业务价值

- **全链路线上化**：将活动招商从线下沟通转为系统化全链路管理，选品→提报→审批→投放闭环
- **选品效率提升**：30+ 维度工作台筛选 + 列驱动懒加载，将海量商品筛选响应压到 20s 内
- **审批自动化**：指标驱动条件路由 + Gravity BPMN，按组织 / 城市 / 毛利自动匹配审批链路，减少人工判断
- **提报合规前置**：16 类校验规则强弱分离，不合规商品在提报阶段即被拦截，减少审批返工
- **投放幂等可靠**：聚合去重 + 分布式锁 + 异步重试，保障促销投放最终一致
- **批量运营提效**：5000 行批量处理 + 行级错误隔离，支撑大规模商品提报与导出
